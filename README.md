# VM_CTRL Runtime Bundle

This branch contains one stripped QCD runtime bundle for `amd64` without ROS 2 (`no-ros`).

## Target

- Architecture: `amd64`
- ROS 2: disabled (`USE_ROS2=OFF`)
- Ubuntu: jammy
- Release branch: `release/qcd-amd64-no-ros`
- Release tag format: `qcd0.0.1-amd64-no-ros`

## Layout

- `build/vm_ctrl` - stripped controller binary (no ROS bridge)
- `run.sh` - runtime launcher
- `Config/` - controller configuration
- `RLController/` - packaged policy configuration and checkpoints
- `lib/` - bundled shared libraries
- `third_party/` - bundled runtime dependencies
- `.release_use_ros2` - `OFF`

## Run

```bash
cd vm_ctrl
./run.sh M2v6 sim
```

## Notes

- This bundle does not source ROS 2 and does not require `ros2_ws`.
- Use the matching release branch for your machine only.
- This branch is generated by CI and should not be edited manually.
